# SSH Gate 安全模型

本文描述 **1.0.0 基线**下 SSH Gate 的安全边界和明确不提供的保证。

## 1. 信任边界

SSH Gate 假设：

- Windows 当前用户和本机 SSH 配置由用户控制。
- 远端服务器输出、文件名和文件内容均不可信。
- ChatGPT / MCP 调用方可以请求操作，但不能自行获得本地审批权。
- OpenAI Secure MCP Tunnel 负责受支持的远程连接路径；SSH Gate 不自行开放公网端口。

本项目不是远端主机沙箱，也不是 Windows 终端安全产品。它的目标是缩小可远程调用能力，并把敏感确认留在本机。

## 2. 本地审批

MCP 不暴露“批准请求”“修改授权策略”“录入密码”“接受新指纹”等工具。

需要人工确认的请求必须经过 WebView 内的本地桥接。审批票据：

- 与具体请求 ID 和摘要绑定；
- 有有效期；
- 只能使用一次；
- 请求内容变化后不能复用旧票据。

前端的按住确认只是一层误触保护；真正的请求一致性校验在后端完成。

## 3. 自动只读准入

自动授权基于解析后的 argv、操作类别和路径范围，不按字符串关键词简单放行。

明确不会自动按只读执行的典型情况：

- shell 管道、重定向、多命令组合和替换；
- `find -delete/-exec/-execdir/-fprint`；
- Git 写操作和外部 diff/textconv/output 行为；
- Docker restart/exec/build/cp 等写操作；
- 未识别选项或无法可靠解析的脚本。

`python_tests` 是显式信任类别。pytest 会执行项目代码，因此即使命令形式受限，也不能把它视为操作系统意义上的只读。

## 4. SSH 主机身份

- 已知主机按 `known_hosts` 校验。
- 未知主机在本地展示 SHA256 指纹，由用户选择仅本次信任或保存。
- 指纹不匹配直接失败，不提供“忽略并继续”的远程接口。
- ProxyJump 链的每一跳独立校验。

前端指纹图只用于辅助辨认，完整 SHA256 文本才是核验依据。

## 5. 凭据存储

当前 `CredentialStore` 使用 AES-256-GCM：

- 每条记录使用随机 96-bit nonce；
- 使用稳定的 opaque reference 作为 AAD；
- 主密钥为随机 256-bit 数据；
- 密文和主密钥默认分离存放。

不会写入 `config.json` 的内容包括：

- SSH 密码
- 私钥口令
- 选择记住的 Tunnel Runtime API Key

运行中的秘密不会出现在 MCP 快照、命令行参数或审计日志中。认证失败导致已保存凭据失效时，相关记录会清除并重新要求本地输入。

### 当前限制

`FileKeyProvider` 主要防止把源码目录、配置文件或日志误提交后直接泄露明文。拥有当前 Windows 用户文件读取权限的攻击者仍可能同时获得密文与主密钥。若需要更强的本机隔离，应实现 Windows DPAPI / Credential Manager 等系统级 `KeyProvider`。

## 6. 私钥与 SSH agent

- 私钥文件始终从本机读取，不上传到跳板。
- 私钥口令只在本地输入。
- `IdentitiesOnly yes` 会限制尝试身份。
- 不启用 agent forwarding。
- 跳板只承担 SSH channel 转发，不会接收到目标机 shell 命令。

## 7. 命令执行

远端命令按已审批的字面脚本执行，SSH Gate 不提供隐藏脚本、编码后执行或远程修改审批摘要的机制。

命令终止采用远端进程组验证。以下情况不保证被终止：

- 程序自行 `setsid` / daemonize；
- 提交给 Docker daemon、systemd、队列系统等其他管理器的后台任务；
- 网络中断使清理过程无法确认。

因此调用方必须检查终止确认结果，而不是把 terminate API 返回本身当成最终成功。

## 8. 文件系统与 SFTP

结构化文件工具避免用 shell 拼接任意文件路径。路径和 ZIP 内容会做边界校验，包括：

- 绝对路径/根目录范围检查；
- 最终符号链接与目录符号链接限制；
- ZIP traversal、绝对路径、符号链接、重复成员、加密成员与异常展开拒绝；
- 上传大小和 SHA256 校验；
- 默认不覆盖远端文件。

传输缓存本身可能含有真实敏感文件，使用完成后应清理。

## 9. Tunnel 与代理

MCP 和 Tunnel 只使用回环地址连接。代理配置仅影响 Tunnel 云控制面/下载链路，并明确设置本地地址绕过代理。

手动持久配置拒绝带 userinfo 的代理 URL。确需代理认证时，可以在启动应用前通过受支持的本机环境变量提供；界面、日志和快照应隐藏认证信息。

HTTPS 诊断始终校验证书，没有“跳过 TLS 校验”的选项。

## 10. 日志与审计

`logs/audit.jsonl` 用于记录：

- request ID
- 请求摘要
- 状态变化
- 自动/人工准入类型
- 终止相关事件

它不应记录密码、私钥内容、API Key 或完整命令输出。日志目录仍属于本地敏感数据，应按普通运维日志处理。

## 11. 不提供的保证

SSH Gate 1.0.0 不承诺：

- 对已被入侵的 Windows 用户环境保护凭据；
- 把远端 Linux 账号限制成真正的 OS 沙箱；
- 可靠终止已经逃离原进程组的后台工作；
- 从浏览器 UI 还原 stdout/stderr 的真实微秒级交错顺序；
- 用 `/readyz` 证明 ChatGPT 工作区权限或插件授权一定正确。
